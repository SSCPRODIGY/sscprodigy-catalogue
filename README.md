# SSC PRODIGY Catalogue

Data file for the SSC PRODIGY website: tests, courses and PDF notes.

- `catalogue.js` is loaded by the site from  
  `https://cdn.jsdelivr.net/gh/SSCPRODIGY/sscprodigy-catalogue@main/catalogue.js`
- Do not edit it by hand. Open `catalogue-manager.html`, make changes, press **Export**, and upload the new file here (same name).
- After uploading, purge the CDN cache so changes show immediately:  
  `https://purge.jsdelivr.net/gh/SSCPRODIGY/sscprodigy-catalogue@main/catalogue.js`

Keep this repo **public** and keep the branch name `main`.
